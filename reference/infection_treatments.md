# Infection treatments dataset

A teaching dataset used in \*Reproducible Research Using R\*. This
dataset is used for examples involving categorical data analysis and
group comparisons.

## Usage

``` r
infection_treatments
```

## Format

A data frame with 150 rows and 2 variables:

- Infection:

  Type of infection.

- Treatment:

  Treatment administered.

## Source

Created for the textbook \*Reproducible Research Using R\*.
